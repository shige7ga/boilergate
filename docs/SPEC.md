# BoilerGate 機能仕様書

> 本書は BoilerGate の機能仕様を定めたものである。実装中に仕様と矛盾・不明点が生じた場合は、実装前に指摘して確認すること。
> 数値（問題数・試験時間・合格基準など）は 2級ボイラー技士試験の公式情報（安全衛生技術センター）で最終確認すること。

## 1. サービス概要

BoilerGate は、2級ボイラー技士試験の合格を目指す初学者向けの学習Webアプリである。

Progate のように、短いスライド学習と問題演習を組み合わせることで、専門知識がない人でも段階的に理解を深められる学習体験を提供する。

### 基本コンセプト

- 知識ゼロから始められること
- 1回5〜10分程度の短い単位で学習できること
- 専門用語を図解や身近な例から理解できること
- 間違えた問題を何度でも復習できること
- 基礎学習から本番形式の模擬試験まで一貫して学習できること

### 設計原則

- 次に何をやればよいかが常に分かる（「次はここ」を示す）
- 間違えても責めず、すぐ復習へ戻れる
- 進行は強く制限せず、ユーザーが自分のペースで進められる

## 2. 対象ユーザー

- 2級ボイラー技士の資格取得を目指す人
- ボイラーに関する専門知識がほとんどない初学者
- テキスト中心の学習では理解が難しい人
- まとまった学習時間を確保しにくい人

## 3. 学習コンテンツ構成

コンテンツは「科目 → セクション → レッスン → スライド」の階層で管理する。

```
科目（4つ）
 └ セクション
    ├ レッスン（スライド → 練習問題）
    └ 確認テスト（セクション末）
模擬試験（全科目横断）
```

### 3.1 科目

本試験の4科目に対応する。

1. ボイラーの構造に関する知識
2. ボイラーの取扱いに関する知識
3. 燃料及び燃焼に関する知識
4. 関係法令

### 3.2 セクション

関連する複数のレッスンをまとめた学習単位。

- 1セクションにつき3〜5レッスン程度
- セクションの最後に確認テストを配置する
- 学習内容のまとまりを優先して分量を調整する

### 3.3 レッスン

1つのテーマについて、スライド学習と練習問題を行う単位。

- 1レッスンにつき4〜7枚程度のスライド
- スライド終了後に2〜3問程度の練習問題
- 目標学習時間は5〜10分程度

## 4. 進行ルール

- **ロックは行わない**。レッスン・セクション・確認テスト・模擬試験のいずれも、いつでも開始できる
- 確認テストの80%は「理解度の目安」であり、未達成でも次へ進める
- 代わりに「推奨順」「次に学習する推奨レッスン」を表示し、迷わないようにする
- 模擬試験は MVP 後に実装する（着手時に解放条件などを改めて決める）

## 5. スライド学習機能

### 目的

専門知識のないユーザーが、1つずつ知識を理解できるようにする。

### 表示内容

- レッスン名
- スライドタイトル
- 解説文
- 必要に応じたイラスト・図解
- 現在のスライド位置
- 前へ・次へボタン

### 挙動

- 1画面に原則1つの主要概念を表示する
- ボタン操作で前後のスライドに移動する
- 最後のスライドから練習問題へ進める
- 学習中でもセクション一覧へ戻れる
- 再学習は何度でも可能とする

### コンテンツ作成方針

- 難しい専門用語は**初出時にスライド本文中で説明する**（MVP）
- 文章量を抑え、段階的に説明する
- 必要に応じて図解を用いる
- 単なる暗記だけでなく、仕組みや理由を解説する
- 後続の練習問題と内容を対応させる

## 6. 練習問題機能

### 目的

直前のスライドで学んだ内容を、自分で解答することで理解を深める。

### 出題形式

- 1問ずつ表示
- 2〜4択程度の選択式
- 基本的に1つの正解を選ぶ形式
- 1レッスンにつき2〜3問程度

### 挙動

1. 問題と選択肢を表示する
2. ユーザーが解答を選択する
3. 「回答する」ボタンで正誤判定する
4. 正解・不正解を表示する
5. 正しい選択肢とその理由を解説する
6. 次の問題に進む

### 仕様

- 解答確定後は正解と解説を表示する
- **不正解のときは、該当するスライドへ戻れるリンクを表示する**
- 不正解でも次へ進める
- 最後の問題まで解答するとレッスン完了
- 何度でも再挑戦可能
- 合格点などの厳格な進行制限は設けない

## 7. セクション確認テスト機能

### 目的

セクション内の複数レッスンについて、知識が定着しているか確認する。

### 出題形式

- 5〜10問程度の選択式
- 原則4択
- セクション内の複数の学習テーマから出題
- 解答中は正誤を表示しない

### 挙動

1. テストを開始する
2. 1問ずつ問題に解答する
3. 全問解答後、採点する
4. 正答数・正答率を表示する
5. 問題ごとの正解と解説を確認できる
6. 再挑戦またはセクション一覧へ戻る

### 習熟度判定

- 正答率80%以上を「理解度の目安達成」とする
- 80%未満の場合は復習を推奨する
- 未達成でも次のセクションへ進める
- 再挑戦は回数無制限
- 過去最高得点を保存する
- **再挑戦時は、問題の順序と選択肢の順序をシャッフルする**（解説文は「選択肢ア」のように位置に依存した書き方をしない）

## 8. 模擬試験機能（MVP後に実装）

### 目的

実際の2級ボイラー技士試験と同等の出題条件で、試験対策を行う。

### 出題形式

- 全40問
- 4科目から各10問
- 五肢択一式
- 試験時間180分
- 問題ごとの正誤は解答中に表示しない

### 試験中の操作

- 前の問題・次の問題へ移動
- 解答済み・未解答の状態を確認
- 選択した解答を変更
- 残り時間を表示
- 解答の途中でも試験を終了して採点可能

### 採点・合格判定

以下の両条件を満たした場合のみ合格とする。

- 全40問中24問以上正解
- 4科目すべてで10問中4問以上正解

未解答の問題は不正解として扱う。

### 試験結果

- 合格・不合格
- 総合正答率
- 正答数
- 科目別正答数・正答率
- 問題ごとの正誤と解説
- 苦手科目の表示

### 再挑戦

- 何度でも受験可能
- 可能な範囲で問題の出題順を変更
- 問題数が十分に増えた段階で問題抽選に対応
- 受験結果の履歴を保存する

### 着手時に改めて決める事項

- 中断・再開の可否と保存方法
- 解放条件（常時可能とするか）
- 問題プールからの抽選ルール

## 9. 学習進捗管理

### 保存する情報

- 完了したレッスン
- レッスンごとの練習問題実施状況
- セクション確認テストの最高点
- 模擬試験の受験結果（MVP後）
- 途中まで進めた学習位置
- **問題ごとの解答履歴**（問題ID、正誤、解答回数、正解回数、不正解回数、最終解答日時）
  - MVP では復習専用画面は作らないが、後から「間違えた問題の復習」を追加できるよう、履歴は最初から保存する

### 進捗表示

- 科目別のレッスン完了率
- 完了済みレッスンの表示
- 確認テストの実施状況
- 次に学習する推奨レッスン

### 保存方法

- LocalStorage を使用
- アカウント登録不要
- 同じブラウザからアクセスした場合に進捗を復元
- 保存データには `version` を持たせ、将来のスキーマ変更に対応できるようにする
- LocalStorage の読み込み失敗・不正データ時は、アプリが落ちないよう初期状態にフォールバックする
- 学習データの初期化機能を用意する
- ブラウザや端末間の同期は行わない

## 11. UI・UX方針

- 初学者にわかりやすい日本語を使用する
- 一度に表示する情報量を抑える
- 主要な操作ボタンを見つけやすくする
- PC・スマートフォン両方に対応する（スマートフォンでの片手操作を意識し、タップ領域は十分な大きさにする）
- スライドや問題の進行状況を表示する
- 正誤を色だけに依存せず文字でも表示する
- 学習途中で迷わず戻れるようにする
- アニメーションや装飾を増やしすぎない
- 「本アプリは非公式の学習補助アプリであり、合格を保証するものではありません」という旨を、設定画面またはフッターに表示する

## 12. 技術構成・制約

README の技術方針を維持する。

- React / TypeScript / Vite
- SPA
- Docker / Docker Compose
- LocalStorage による進捗保存
- 学習コンテンツはローカルの静的データで管理
- バックエンド・データベース・AI API は使用しない
- 新規ライブラリは必要な場合のみ導入し、理由を説明する
- 過度な抽象化を避け、保守しやすい構成とする

### コンテンツのデータ構造（方針）

科目・セクション・レッスン・スライド・問題は、型定義を固定し、静的データとして管理する。コンテンツの追加が型に沿ってデータを書くだけで済む構成にする。

- 問題（Question）には、将来の出題形式（用語の一問一答など）を追加できるよう、出題形式を表す `type` を持たせる。現時点では選択式（`choice`）のみ実装する
- 問題は、どのレッスンの内容に対応するか（`lessonId`）を持つ。「不正解時に該当スライドへ戻るリンク」には、問題と対応するスライドの紐付け（`slideId` など）も持たせる
- ID は、保存データ（解答履歴・進捗）から参照されるため、一度決めたら変更しない

## 13. MVP対象

最初のMVPでは、学習体験の基本フローを優先し、**1科目を縦に完成させる**。

### 初期実装範囲

- 学習ホーム
- 1科目の一部セクション
- 3レッスン程度のスライド学習
- レッスンごとの練習問題
- セクション確認テスト
- LocalStorage による進捗保存（問題ごとの解答履歴を含む）
- PC・スマートフォン対応

### 実装順（目安）

1. 型定義、サンプルデータ、ルーティング、学習ホーム〜セクション詳細
2. スライド学習
3. 練習問題
4. 確認テスト・結果画面
5. LocalStorage による進捗保存・推奨レッスン表示・初期化

### MVP後の拡張

- 4科目すべての学習コンテンツ
- 全セクションの確認テスト
- 40問・180分の模擬試験
- 模擬試験履歴・苦手科目分析
- 問題数の拡充と出題ランダム化
- 間違えた問題の復習機能（専用画面）
- 用語の一問一答形式の問題（用語確認ドリル）
- スライド内の用語タップ解説・用語集

## 14. 初期段階では実装しないもの

- ユーザー登録・ログイン
- バックエンドAPI・データベース
- AIによる問題生成や解説
- ランキング・ユーザー間交流
- 経験値やレベルアップ機能
- 複雑な管理画面・CMS
- クラウドへの進捗同期

まずは基本的な学習体験を完成させ、その後に必要な機能を追加する。

## 15. 教材品質の管理

- 問題ごとに正解と解説を用意する
- スライドの内容と練習問題の整合性を確認する
- 関係法令は適用時点を意識して定期的に確認する
- 公式の公表試験問題は、出題傾向を把握するための参考資料として使用する。**問題文・選択肢は転載せず、オリジナルで作成する**（公表問題の利用条件は別途確認する）
